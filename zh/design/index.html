一、AI 与设计的碰撞（5篇）

5. Chat is AI's command line Wattenberger 的观点：AI 应该让我们更有能力，而不是仅仅给我们一个"更有能力的对话对象"。对当前 Chat 交互范式的深刻反思。 🔗 https://wattenberger.com/thoughts/ai-is-still-in-its-terminal-era/
