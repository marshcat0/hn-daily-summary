🔗 原文：https://is-agentic.com/

Balsa UI —— 面向 Agent 的原生开源组件系统（支持 Vue 和 React）。当 AI Agent 开始自主操作界面时，传统面向人类的 UI 组件需要重新设计。Balsa UI 试图定义“Agent 可理解”的组件规范，是值得关注的探索方向。
