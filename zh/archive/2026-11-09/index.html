一、AI 时代的设计师角色与设计系统

1. Otherwise you're just a machine 核心观点：AI 在设计上越来越强，设计师也必须进化，否则会被降格为“机器”。值得关注的是它把 AI 当作对设计师能力的倒逼，而非威胁叙事。 链接：https://uxdesign.cc/otherwise-youre-just-a-machine-a9d3b21179b5

2. What does design system AI readiness mean, anyway? 作者提出一个反直觉判断：设计系统的“AI 就绪”不在于产出机器可读的工件，而在于明确人类在回路中的位置。对正在做 design token / 组件库 AI 化的团队很有参考价值。 链接：https://seanvoisen.com/writing/design-system-ai-readiness/

3. Designing a skill 把“技能（skill）”类比为 agent 时代的 App，并指出做高质量软件的经验依然适用。这是把产品设计思维迁移到 agent 能力设计上的一篇方法论短文。 链接：https://iamnoman.com/writing/designing-a-skill

二、AI 产品的可控性与交互边界

4. Everyone is building AI agents. Who's designing the stop button? 讨论 AI 的非确定性如何与产品所需的确定性冲突，最难的决策发生在“自主性结束的地方”。这是今日最具产品设计批判性的一篇。 链接：https://uxdesign.cc/your-ai-is-non-deterministic-but-your-product-cant-be-3ec2a0cf870c

5. Mean 一个具体的产品案例：面向人和 agent 的视觉交接工具，可冻结/录制屏幕、用手势标注，再把会话交给人类或 AI。可作为“人机协作界面”的实物样本。 链接：https://mean.app/

三、字体与视觉设计

6. A sans serif built on oversized round shapes Superior Type 的 Heaven：以“超出空间”的超大圆形构建的粗野主义 grotesque 字体。对品牌与字体设计爱好者是直接的视觉灵感来源。 链接：https://the-brandidentity.com/typeface/superior-types-heaven-is-a-sans-serif-built-on-oversized-round-shapes
