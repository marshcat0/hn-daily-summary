二、AI 编码工具的安全风险

2. Claude Code's "Don't Ask Again" exposes passwords in 1,122 public GitHub files

说明：Anthropic 的 Claude Code 中"不再询问"选项导致密钥/密码被写入 1,122 个公开 GitHub 文件。这是 AI 编码代理（coding agent）落地中最典型的安全事故模式——便利性设置与密钥管理的冲突，对任何在生产中使用 AI 编程工具、或维护代码扫描/CI 密钥检测的团队都有直接警示价值。

  • 原文：https://apiiro.com/blog/coding-agents-leaking-secrets-github-dont-ask-again
  • 讨论：https://news.ycombinator.com/item?id=50407882
