## 一、🔐 安全漏洞与隐私

### 1. Chromium 全版本沙箱逃逸漏洞（CVE-2026-85046）—— 正在被积极利用
这是今天最值得警惕的安全新闻。**所有 Chromium 版本**均受影响，且漏洞已被野外利用。NVD 已发布详情，属于沙箱逃逸级别的 RCE，影响范围涵盖 Chrome、Edge、Brave 等所有基于 Chromium 的浏览器。
- **文章**：https://nvd.nist.gov/vuln/detail/cve-2026-85046
- **讨论**：https://news.ycombinator.com/item?id=49570669

### 2. Mullvad 关闭公共加密 DNS，转而赞助 Quad9
知名隐私 VPN 服务商 Mullvad 宣布关闭其公共加密 DNS 服务器，转而赞助 Quad9。这一决定反映了维护公共 DNS 基础设施的高昂成本，以及隐私服务领域的分工整合趋势。
- **文章**：https://mullvad.net/en/blog/shutting-down-our-public-encrypted-dns-servers-and-sponsoring-quad9-instead
- **讨论**：https://news.ycombinator.com/item?id=49568579

### 3. 成人电影制片人揭发 Meta 高管为著名盗版者 "John DOE"
TorrentFreak 报道，一位成人电影制片人通过法律手段，揭露了长期活跃的种子盗版者 "John DOE" 的真实身份——竟是 Meta 公司的一名高管。该事件引发了对大公司高管道德标准的广泛讨论。
- **文章**：https://torrentfreak.com/adult-film-producer-unmasks-prolific-john-doe-torrent-pirate-as-meta-executive/
- **讨论**：https://news.ycombinator.com/item?id=49567053

### 4. "永久化学品"（PFAS）灾难如何被掩盖
ProPublica 的播客深入调查了 3M 公司如何长期隐瞒 PFAS（全氟烷基物质）的危害。这虽然不是纯技术新闻，但涉及化工技术伦理与公众健康的重大议题。
- **文章**：https://www.propublica.org/podcast/forever-chemicals-pfas-pfos-3m-secret-kris-hansen
- **讨论**：https://news.ycombinator.com/item?id=49576986

### 5. deSEC——免费安全 DNS 服务
在 Mullvad 退出公共 DNS 的同时，deSEC 作为免费安全 DNS 服务受到关注。它提供 DNSSEC 支持和 API 管理，是自托管和隐私爱好者的替代选择。
- **文章**：https://desec.io/
- **讨论**：https://news.ycombinator.com/item?id=49566193
