二、AI 编码工具的安全风险

2. Claude Code's "Don't Ask Again" exposes passwords in 1,122 public GitHub files

说明：Anthropic 的 Claude Code 中"不再询问"选项导致密钥/密码被写入 1,122 个公开 GitHub 文件。这是 AI 编码代理（coding agent）落地中最典型的安全事故模式——便利性设置与密钥管理的冲突，对任何在生产中使用 AI 编程工具、或维护代码扫描/CI 密钥检测的团队都有直接警示价值。

  • 原文：https://apiiro.com/blog/coding-agents-leaking-secrets-github-dont-ask-again
  • 讨论：https://news.ycombinator.com/item?id=50407882

3. The Components of Agent Memory

说明：Anthropic 官方研究文章，系统拆解 AI Agent 记忆的组成要素。对正在构建 LLM Agent、需要设计上下文管理/长期记忆/检索策略的开发者来说，属于少见的"体系化"参考材料，而非零散工程技巧。

一、AI 时代的设计：Agent、可控性与新界面

这一组是今日最核心的议题——当产品从"确定性界面"转向"非确定性智能体"，设计的关键问题从"怎么画"变成了"边界在哪里"。

1. Everyone is building AI agents. Who's designing the stop button? 探讨 AI 自主性的边界所在，恰恰是最难的设计决策发生的地方——如何为不可预测的系统设计可控的"停止"机制。这是当前 AI 产品设计最被忽视却最关键的问题。 🔗 https://uxdesign.cc/your-ai-is-non-deterministic-but-your-product-cant-be-3ec2a0cf870c

7. Mean 一款面向"人类与 Agent"的视觉交付工具：冻结或录制屏幕、用手势标注，再把完整会话交给人类或 AI。代表了"设计交付对象从人扩展到 Agent"的新品类。 🔗 https://mean.app/

8. Designing a skill 提出"Skill 正在成为 Agent 时代的 App"，并论证交付高质量软件的經驗依然适用于设计 Skill。为设计师提供了进入 Agent 生态的路径思考。 🔗 https://iamnoman.com/writing/designing-a-skill

13. Building an AI-ready design system library 作者主张设计系统应"从代码出发"，并介绍如何用 MCP 构建、校验和维护 Figma 库。是设计系统面向 AI 工作流的实操范例。 🔗 https://uxdesign.cc/building-an-ai-ready-design-system-library-code-figma-with-mcp-ec5d9e8c90d2

二、字体与排版设计（今日最密集的子主题）

四篇字体相关文章从不同角度切入：实验性、工具性、开源性与品牌性。

2. A sans serif built on oversized round shapes Superior Type 的 "Heaven" 是一款建立在"过大圆形"之上的粗野主义 grotesque 字体，是当代字体实验的代表案例，值得关注其形式语言。 🔗 https://the-brandidentity.com/typeface/superior-types-heaven-is-a-sans-serif-built-on-oversized-round-shapes

3. Tokenizer Mono 一款在你打字时高亮 LLM token 的等宽字体——不用 JavaScript，仅靠 OpenType 替换规则和颜色表实现。技术实现极具巧思，是"字体即界面"的典范。 🔗 https://george.mand.is/2026/11/the-tokenizer-font/

15. Paper Mono 8 个可变字重、带编码连字、免费开源的等宽字体家族。对开发者与设计师都是实用的高质量资源。 🔗 https://paper.design/mono

14. The window with no buttons 探讨为什么终端对设计师如此陌生，以及如何读懂它。对想跨越"图形界面 vs 命令行"鸿沟的设计师很有启发。 🔗 https://www.baselinedesign.com/posts/the-window-with-no-buttons
