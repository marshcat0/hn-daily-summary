## 一、AI 与设计实践的碰撞

这一组文章集中探讨 AI Agent、对话式界面如何重塑设计工作流与产品形态。

**1. Agents don't need memory. They need documentation.**
核心观点：AI Agent 不需要从旧对话中检索记忆，而需要结构化的项目文档。这对设计团队如何组织设计规范、组件文档有直接启发。

**5. Chat is AI's command line**
作者（Wattenberger）提出：聊天界面只是 AI 的"命令行阶段"，真正的目标是让 AI 增强人的能力，而非仅仅提供一个"更厉害的对话对象"。这是对当前 chat UI 霸权的有力反思。
- 原文：https://wattenberger.com/thoughts/ai-is-still-in-its-terminal-era/

**11. Prompting as self-portrait**
将"写 prompt"视为一种自我肖像创作——AI 在空白页上安装了一面扭曲的镜子。适合关注创作心理与 AI 交互的设计师。

**13. Is Meta's new AI agent easier to trust because it's cute?**
分析 Meta 的 AI Agent "Muse"：可自定义头像 + 钥匙扣硬件，尽管信任度存疑，却登顶美国 App Store。探讨"可爱"作为信任设计策略的伦理边界。
- 原文：https://uxdesign.cc/is-metas-new-ai-agent-easier-to-trust-because-it-s-cute-c8de13aefc6f

**14. Many agents, many views**
Luke Wroblewski 关于多 Agent 层级管理的思考：你管理 Agent，Agent 管理更多 Agent。对多 Agent 产品的信息架构设计极有参考价值。
- 原文：https://www.lukew.com/ff/2165/many-agents-many-views
