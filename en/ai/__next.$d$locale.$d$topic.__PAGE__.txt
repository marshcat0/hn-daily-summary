## 一、AI 编程工具与供应链安全（今日热度最高）

**1. Cursor Marketplace 上 Claude Code VS Code 扩展被植入后门**
- 为什么值得关注：HN 今日最高分（994 分、553 条评论）。官方 Claude Code 扩展在 Cursor 市场出现被篡改版本，属于典型的 AI 开发工具供应链攻击，直接威胁大量开发者的代码与密钥安全。Cursor 官方已发布安全公告。
- 原文：https://phorion.io/blog/offical-claude-code-vsx-compromise/
- 官方公告：https://cursor.com/blog/claude-code-extension-security-notice
- 讨论：https://news.ycombinator.com/item?id=50300683

**3. JavaScript 框架的"AI 成本"**
- 为什么值得关注：Nolan Lawson 探讨前端框架选择如何影响 AI 编码工具（如 LLM 生成、代码补全、上下文长度）的成本与效果，对工程选型有实际参考价值。238 条评论显示争议不小。
- 原文：https://nolanlawson.com/2026/10/28/the-ai-cost-of-javascript-frameworks/
- 讨论：https://news.ycombinator.com/item?id=50323088

**8. 不用 AI，52 分钟纯手写实现全部 Linux 文件工具（视频）**
- 为什么值得关注：与"vibe coding"形成鲜明对照的行为艺术式实验，引发关于 AI 辅助编程是否削弱基本功的讨论。
- 原文：https://www.youtube.com/watch?v=gQRmSlcTq9c
- 讨论：https://news.ycombinator.com/item?id=50290480
