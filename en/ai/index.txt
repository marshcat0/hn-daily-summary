## 一、模型发布与能力探索

### 1. Gemini 4 Carbon（839 分 / 700 评论）🔥
**为什么值得关注**：今日热度最高的条目，Google 官方博客发布 Gemini 4 Carbon 模型介绍，700 条评论说明社区讨论极为激烈，是了解新一代 Gemini 能力边界与定价策略的第一手材料。
- 原文：https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-carbon/
- 讨论：https://news.ycombinator.com/item?id=50276792

### 7. Qwenputer: 在 Qwen3.5 内部运行一个可工作的确定性 RISC-V CPU（184 分 / 41 评论）
**为什么值得关注**：一个颇具极客趣味的实验——把 RISC-V CPU 模拟"塞进"LLM 内部并保持确定性行为，涉及模型内部计算与可解释性/可控性话题，适合关注 LLM 机制的人。
- 原文：https://divagr.com/blog/qwenputer
- 讨论：https://news.ycombinator.com/item?id=50282838

## 二、LLM 研究与持续学习

### 10. Sleep framework：让 LLM 在持续学习中保留知识的新方法（41 分 / 3 评论）
**为什么值得关注**：Google Research 官方博客，直击 LLM 持续学习中的灾难性遗忘问题，"睡眠"式知识巩固机制是当前研究热点，评论虽少但内容价值高。
- 原文：https://research.google/blog/the-sleep-framework-a-new-way-for-llms-to-retain-knowledge-in-continual-learning/
- 讨论：https://news.ycombinator.com/item?id=50272479

### 2. Survival LLM：可在个人电脑上运行的 AI 助手与应急知识库（523 分 / 194 评论）
**为什么值得关注**：本地化、离线可用的 LLM 应用，契合"断网/应急场景"需求，也反映了社区对本地推理与数据主权的持续兴趣。
- 原文：https://www.brangus.io/survival-llm
- 讨论：https://news.ycombinator.com/item?id=50264853

## 三、AI Agent 与工程实践

### 5. Dayjob: Tax —— 在 50 个专业税务任务上评测 AI Agent（215 分 / 139 评论）
**为什么值得关注**：面向真实专业场景（税务）的 Agent 基准评测，比通用 benchmark 更能暴露 Agent 在合规、准确性上的短板，对做垂直 Agent 的团队有直接参考价值。
- 原文：https://surgehq.ai/blog/dayjob-tax
- 讨论：https://news.ycombinator.com/item?id=50275626

### 8. The Agent SDK（105 分 / 115 评论）
**为什么值得关注**：Cursor 发布 Agent SDK，评论数超过分数，说明开发者对"如何构建/集成 Agent"的工程化路径高度关注，是 Agent 基础设施方向的重要信号。
- 原文：https://cursor.com/blog/agent-sdk
- 讨论：https://news.ycombinator.com/item?id=50273731

### 14. Claude Code 在一个 3 词状态行上消耗约 15–20% 的 token（5 分 / 0 评论）
**为什么值得关注**：一个具体的成本优化案例，揭示 AI 编码工具中隐性的 token 浪费，对使用 Claude Code 的团队有实际省钱意义；热度低但实用性强。
- 原文：https://gist.github.com/flamerix-ai/c3905705cc4205e5de3011fa2e74efce
- 讨论：https://news.ycombinator.com/item?id=50284255

### 13. 用 AI 反编译游戏：Virtueel Zoetermeer（18 分 / 2 评论）
**为什么值得关注**：AI 辅助逆向工程/反编译的具体实践案例，展示了 LLM 在代码理解与遗留系统分析中的落地方式。
- 原文：https://bou.ke/blog/zoetermeer/
- 讨论：https://news.ycombinator.com/item?id=50273416
