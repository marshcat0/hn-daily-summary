## 一、AI 与设计/开发的关系反思

**1. What happens when you can build it all yourself**
探讨"构建速度"如何改变我们对注意力、期望值以及创业融资的认知。当一个人借助 AI 能独立完成所有构建时，速度带来的心理代价值得深思。
🔗 https://www.renatovaldes.com/essays/what-happens-when-you-can-build-it-all-yourself/

**2. AI is a boring technology**
作者认为 AI 本身并不比它帮助你完成的事情更有趣——这是一种褒义的"无聊"。对设计从业者而言，这提醒我们回归"AI 用来做什么"而非"AI 本身多酷"。
🔗 https://www.chrbutler.com/ai-is-a-boring-technology

**3. The lie we keep telling ourselves about regulating AI**
从 UX 设计视角审视 AI 监管问题。"没人能达成共识"这个借口，在互联网缔造者看来是可笑的。
🔗 https://uxdesign.cc/the-lie-we-keep-telling-ourselves-about-regulating-ai-61e0163d795e

**4. How to keep enjoying programming in a world of LLMs**
Haskell 社区关于"在 LLM 时代如何保持编程乐趣"的讨论。直面"被低技能但拥有大量 Claude 额度的人取代"的焦虑，对开发者心理状态有共鸣价值。
🔗 https://discourse.haskell.org/t/how-to-keep-enjoying-programming-in-a-world-of-llms/14705

**5. Do frameworks matter anymore?**
探讨抽象层如何约束 AI Agent，帮助工程团队评估长期 Web 架构选择。对前端设计系统与架构决策有参考意义。
🔗 https://brookslybrand.com/posts/do-frameworks-matter-anymore/


## 二、AI 界面组件与设计资源

**6. Thinking orbs**
一个 React 组件库，提供精心制作的动画"思考球"——用于 AI 的 thinking、searching、compacting 等状态指示器。免费开源，直接可用于 AI 产品 UI。
🔗 https://www.thinkingorbs.com/

**7. Agent skill: Libraries.dev**
教你的编程 Agent 使用 Border beam、Thinking orbs、Gooey、Voice、Bot avatars、Liquid metal 和 Image 等设计元素。面向"AI Agent 时代的设计工具链"。
🔗 https://libraries.dev/skill

**8. The WebGPU library, designed for agents**
面向 Agent 设计的 WebGPU 库，支持全屏着色器、计算管线、原生 WebGPU 互操作。代表了"为 AI Agent 而设计"的新一类开发工具。
🔗 https://vgpu.sh/examples

**9. Google's 3D emoji design process**
Google 如何将 3,977 个 Noto emoji 带入 3D。是视觉设计与 3D 工艺结合的深度案例，对表情/图标设计有直接参考价值。
🔗 https://design.google/library/noto-3d-emoji-design


## 三、前端技术与文档工具

**10. Blume**
面向人类和 Agent 的开源文档框架。把 Markdown 丢进文件夹即可发布快速文档站点。对技术文档设计和开发者体验有实用价值。
🔗 https://useblume.dev/

**11. Modern web types**
TypeScript 有意不支持所有新 API，但有一个简单的修复方法。对前端开发者的类型系统实践有直接帮助。
🔗 https://philipwalton.com/articles/modern-web-types/

**12. Sidenotes with CSS anchor positioning**
用 CSS anchor positioning 实现边注（sidenotes），无需 JavaScript，在窄视口和旧浏览器中优雅降级。是排版设计与现代 CSS 结合的优秀范例。
🔗 https://vincent.bernat.ch/en/blog/2026-css-sidenotes


## 四、行业观察与人文思考

**13. State of Devs 2026**
年度开发者调查：近半数受访者经历过工作不安全和薪资不足。对理解设计/开发从业者的职业处境有数据价值。
🔗 https://2026.stateofdevs.com/en-US/

**14. I can't tell who's teaching who anymore**
关于继承母亲的句子，却看着它们被读成机器的语言。一篇关于语言、传承与 AI 的散文，触及设计中"人味"的核心命题。
🔗 https://blog.murphytrueman.com/i-cant-tell-whos-teaching-who-anymore/

**15. Online hacker simulator**
交互式在线黑客模拟器，让你模拟入侵电脑或数字网络。属于趣味互动设计，可参考其沉浸式体验的营造方式。
🔗 https://hacker-simulator.com/
