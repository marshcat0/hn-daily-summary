### 一、 AI与设计：工具、人格与创造力

这个主题是今日最热门的焦点，涵盖了 AI 作为设计工具、设计对象以及其带来的哲学思考。

1.  **Claude Cookbook**
    *   **说明**: 这是一份实用的代码和指南合集，帮助设计师和开发者利用 Claude 进行构建。它涵盖了提示工程、工具使用和多模态能力，是 AI 辅助设计的实操手册。对于希望将 AI 集成到工作流中的设计师来说非常实用。
    *   **文章链接**: [https://platform.claude.com/cookbook/](https://platform.claude.com/cookbook/)
    *   **讨论链接**: 无

2.  **The algorithmic atelier**
    *   **说明**: 文章探讨了生成式 AI 与艺术自动化漫长历史的关系。它将 AI 创作置于更广阔的艺术史背景中，帮助设计师理解当前 AI 工具的“新”与“旧”，从而更批判性地使用它们。
    *   **文章链接**: [https://www.doc.cc/articles/the-algorithmic-atelier](https://www.doc.cc/articles/the-algorithmic-atelier)
    *   **讨论链接**: 无

3.  **Which AI? — Guess the designer**
    *   **说明**: 一个有趣的互动游戏，让用户猜测落地页是由 Gemini、Claude 还是 GPT 设计的。这直接挑战了设计师对 AI 生成界面的识别能力，也反映了当前 AI 设计在风格和模式上的趋同与差异。
    *   **文章链接**: [https://guess-the-designer.replit.app/](https://guess-the-designer.replit.app/)
    *   **讨论链接**: 无

4.  **AI personality is a design problem**
    *   **说明**: 核心观点是：AI 的人格目前是“对齐”工作的意外副产品，但它完全可以被设计成一种有意的交互界面。这为 UI/UX 设计师提出了一项新使命：设计 AI 的“性格”，而不仅仅是其界面。
    *   **文章链接**: [https://uxdesign.cc/ai-personality-is-a-design-problem-58fbc7926a3d?sk=b159b61f2abcb25776fd87985724be7e](https://uxdesign.cc/ai-personality-is-a-design-problem-58fbc7926a3d?sk=b159b61f2abcb25776fd87985724be7e)
    *   **讨论链接**: 无

### 二、 产品思维与设计哲学

这部分文章从宏观和哲学层面探讨了产品设计、个人工具和设计工作的本质。

5.  **A concrete definition of “Product Sense”**
    *   **说明**: 来自 NN/g 的专业定义，将“产品感”具体化为一种预测能力。它基于实验模式来预判产品决策能否成功，并懂得何时应用这些模式。这是产品设计师职业发展的核心概念，值得深入理解。
    *   **文章链接**: [https://www.nngroup.com/articles/product-sense-definition/](https://www.nngroup.com/articles/product-sense-definition/)
    *   **讨论链接**: 无

6.  **The era of personal software**
    *   **说明**: 文章提倡为个人需求量身定制的“个人软件”时代。这与传统的“一刀切”SaaS 模式形成对比，预示了未来设计可能转向高度个性化、小规模甚至一次性的工具，挑战了设计师对“规模化”的固有认知。
    *   **文章链接**: [https://allen.hutchison.org/2025/11/28/the-era-of-personal-software/](https://allen.hutchison.org/2025/11/28/the-era-of-personal-software/)
    *   **讨论链接**: 无

7.  **Make it work vs. make it good**
    *   **说明**: 文章探讨了设计工作从“能运行”到“做得好”的转变。核心观点是，设计的真正价值在于让解决方案好到“显而易见”。这是对设计精益求精精神的深刻反思，适合每个阶段的设计师阅读。
    *   **文章链接**: [https://blog.jim-nielsen.com/2026/make-it-work-make-it-good/](https://blog.jim-nielsen.com/2026/make-it-work-make-it-good/)
    *   **讨论链接**: 无

8.  **A side project is the fastest way to upskill in the age of AI**
    *   **说明**: 作者认为，在 AI 时代，通过做一个真实的副项目来学习技能，速度最快。这为设计师提供了一个避免被 AI 浪潮淹没、主动学习和成长的具体行动指南。
    *   **文章链接**: [https://www.philmorton.co/a-side-project-is-the-fastest-way-to-upskill-in-the-age-of-ai/](https://www.philmorton.co/a-side-project-is-the-fastest-way-to-upskill-in-the-age-of-ai/)
    *   **讨论链接**: 无

### 三、 UI/UX 具体实践与资源

这部分聚焦于具体的 UI 设计细节、动画和资源工具。

9.  **UI SFX**
    *   **说明**: 这是一个提供 78 个开源、语义化的 UI 音效库，有 12 种可切换的风格，适用于网页、移动端、SaaS 和游戏。对于希望提升产品交互细节和可访问性的设计师来说，这是极佳的免费资源。
    *   **文章链接**: [https://uisfx.com/](https://uisfx.com/)
    *   **讨论链接**: 无

10. **On layout choreography**
    *   **说明**: 文章深入探讨了“布局编排”，即如何通过动画在列表重排、面板展开等场景中保持用户的空间记忆。这是高级 UI 动效设计的核心，能显著提升用户体验的流畅度和自然感。
    *   **文章链接**: [https://karlkoch.me/writing/on-layout-choreography](https://karlkoch.me/writing/on-layout-choreography)
    *   **讨论链接**: 无

11. **Setting type like a printed page**
    *   **说明**: 文章详细介绍了如何使用 CSS 实现类似印刷品的排版效果，包括流体缩放、平衡标题、首字母下沉、光学尺寸和悬挂标点等。对于追求极致排版效果的前端和 UI 设计师，这是非常实用的技术指南。
    *   **文章链接**: [https://www.carmenansio.com/articles/editorial-typography-css/](https://www.carmenansio.com/articles/editorial-typography-css/)
    *   **讨论链接**: 无

12. **Visualize striking 3D embellishment mockups**
    *   **说明**: 介绍了一个名为 DREAMCOMPOSER 的工具，可以将设计转化为令人印象深刻的 3D 模型。对于需要制作高保真产品展示图的设计师来说，这是一个能快速提升作品视觉冲击力的工具。
    *   **文章链接**: [https://bit.ly/uxc-dre1](https://bit.ly/uxc-dre1)
    *   **讨论链接**: 无

### 四、 其他值得关注的视角

这部分文章虽不完全属于传统“设计”范畴，但提供了独特的文化或历史视角，值得设计师关注。

13. **The lost joy of music piracy**
    *   **说明**: 文章回顾了 What.CD 和 Oink 等音乐盗版时代的社区感和发现乐趣，对比了现代流媒体的“平庸”。这从用户行为和社区设计的角度，为产品设计师提供了关于“发现”和“归属感”的宝贵思考。
    *   **文章链接**: [https://www.pigeonsandplanes.com/read/music-piracy-what-cd-oink-nine-inch-nails-streaming](https://www.pigeonsandplanes.com/read/music-piracy-what-cd-oink-nine-inch-nails-streaming)
    *   **讨论链接**: 无

14. **Uncovered.ink**
    *   **说明**: 一个有趣的实验性项目，让用户“盲读”书籍的第一页（无封面、无书名、无炒作）。这本质上是一种 UX 测试，探讨了“信息呈现方式”如何影响用户的判断和选择，对内容型产品设计很有启发。
    *   **文章链接**: [https://uncovered.ink/](https://uncovered.ink/)
    *   **讨论链接**: 无

15. **The Java Story (official doc)**
    *   **说明**: 这是一个关于 Java 语言的官方纪录片，讲述了其创新、战略转型和社区故事。虽然与 UI/UX 无直接关系，但作为软件生态的基石，了解其演进历程有助于设计师理解技术平台的变迁和设计约束的由来。
    *   **文章链接**: [https://www.youtube.com/watch?v=ZqGSg4b_cZA](https://www.youtube.com/watch?v=ZqGSg4b_cZA)
    *   **讨论链接**: 无
